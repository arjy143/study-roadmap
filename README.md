# Study roadmap

A personal, day-by-day study plan with tick-off tracking.

**Site:** https://arjy143.github.io/study-roadmap/

## How it works

| Piece | What it does |
|---|---|
| `plan.json` | Every day's tasks, generated by `tools/gen_plan.py` |
| `index.html`, `app.js`, `style.css` | The site — Today, Week, Calendar and Progress views |
| `progress.json` | Ticks and notes, written by the site when sync is on |
| `.github/workflows/daily-reminder.yml` | Every morning (~07:12 UK summer / 06:12 winter) opens an issue with the day's tasks, assigned to you, so GitHub emails it. Yesterday's issue is closed automatically. |
| `.github/workflows/pages.yml` | Deploys the site when site files change |

## Syncing between devices

Ticks are stored in the browser by default. To share them between phone and laptop, open **Progress → Sync across devices** and paste a fine-grained token scoped to this repo only, with *Contents: read and write*. Do this once on each device.

The repo is public, so `progress.json` (ticks and notes) is publicly readable. Keep notes non-sensitive.

## Extending the plan

Add weeks to `WEEKS` in `tools/gen_plan.py` and run `python3 tools/gen_plan.py`. Task ids are date-based, so past ticks are kept.

## Keeping reminders alive

GitHub pauses scheduled workflows in public repos after 60 days without commits. With sync on, ticking tasks commits `progress.json`, which counts. If reminders ever stop, re-enable the workflow under **Actions → Daily reminder**.
